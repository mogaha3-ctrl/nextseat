## 설명 (아래 전체 복사)

```
● 부서 공용 장비(노트북, 빔프로젝터, 측정기, 무전기 등)를 누가 언제까지 빌려 갔는지 한 화면에서 확인하고 대여·반납하는 웹앱입니다.

  ◦ 대여 등록 폼 : 장비를 고르고 반납예정일(오늘~7일 이내)을 선택해 대여
  ◦ 대여 중인 물품 표 : 각 행의 "반납" 버튼을 누르면 반납 시각이 기록되고 장비는 다시 "대여 가능"
  ◦ 요약 카드 : 전체·대여 가능·대여중 (로그인하면 내 대여중·내 연체까지 5개)
  ◦ 반납예정일이 지나면 빨간색으로 연체 표시
  ◦ 장비 등록·수정·삭제 (내가 등록한 장비만), 이름·위치 검색 + 분류·상태 필터
  ◦ 규칙 위반은 DB가 거부하고 이유를 화면에 안내
     (중복 대여, 8일 이상 대여, 남의 기록 반납, 대여 기록이 있는 장비 삭제 등)

● 배포 주소 : https://(Vercel 주소).vercel.app/
   - 가상 접속 아이디 : test1@example.com
   - 비밀번호 : test1234
   (새 가상 이메일로 회원가입해도 바로 사용할 수 있습니다)
```
